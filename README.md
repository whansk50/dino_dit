# DINO DiT
기존의 [DiT(Document Image Transformer)](https://github.com/microsoft/unilm/tree/master/dit)의 Detection Framework에 대해 Cascade R-CNN 사용을 [DINO(DETR with Improved DeNoising Anchor Boxes for End-to-End Object Detection)](https://github.com/IDEA-Research/DINO)로 대체해 그 성능을 벤치마크하는 프로젝트

## 목적
Cascade RCNN의 구조적 한계점 보완 여부와 DETR 구조 및 동작 연구
